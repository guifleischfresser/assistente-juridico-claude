# Bem-vindo(a) ao seu ESCRITÓRIO digital

Tudo aqui fica **no seu computador**. Para trabalhar, abra o Claude Code nesta pasta e converse normalmente, ou use um destes atalhos:

| Digite | Para |
|---|---|
| `/ajuda` | ver tudo o que o assistente faz |
| `/novo-caso` | abrir um caso novo |
| `/nova-peca` | redigir uma peça (inicial, contestação, recurso, contrato, parecer...) |
| `/preparar-autos` | transformar os PDFs do processo em texto leve (economiza seu limite) |
| `/revisar` | revisar uma peça (citações, cara de IA, requisitos) |
| `/advogado-do-diabo` | atacar a peça como faria a parte contrária |
| `/prazos` | ver e calcular prazos |
| `/aprender-meu-estilo` | ensinar o assistente a escrever como você |
| `/handoff` | salvar onde paramos |
